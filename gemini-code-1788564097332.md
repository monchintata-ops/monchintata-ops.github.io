# Ajuste Arquitectura: Separación de Hoja de Impresión vs. Logo para Mockups

## Objetivo
1. Reactivar las prendas: Camisa Negra, Camisa Blanca, Gorra, Taza y Termo.
2. Separar los recursos de imagen:
   - Utilizar `imagen_preview_url` únicamente para mostrar el producto final que se vende (Hoja A3/A4).
   - Utilizar un nuevo campo / fallback `diseno_corte_url` (o extraer la capa transparente) para alimentar el Canvas de `MockupViewer.tsx`.

---

## 1. Configuración de Plantillas (`lib/mockup-config.ts`)
Reincorporar las 5 variantes con sus coordenadas específicas:
- `camisa-negra`
- `camisa-blanca`
- `gorra`
- `taza`
- `termo`

---

## 2. Lógica del Generador (`components/MockupViewer.tsx` / `components/ProductGallery.tsx`)
- Al generar el Canvas, cargar `product.diseno_corte_url` (logo individual) en lugar de la plantilla completa A3.
- Si `diseno_corte_url` no existe, usar `imagen_preview_url` como fallback.
