# Reparación de URL de Preview en las Tarjetas del Catálogo

## Objetivo
Corregir la visualización de las imágenes en las tarjetas del catálogo principal (`/`), asegurando que si la imagen de preview procesada o la URL generada falla o no existe, el componente utilice como fallback directo la imagen original/mockup que sí funciona en la vista de detalle.

---

## 1. Modificación en el Componente de Tarjeta de Producto (`components/ProductCard.tsx` o equivalente)

- Revisar la propiedad `src` de la etiqueta `<img>` o `<Image>` en el catálogo.
- Si la URL del preview está devolviendo un error HTTP (404/500) o viene vacía, aplicar un manejador de error `onError` en el cliente para cambiar automáticamente al campo de la imagen original (`producto.imagen_url` o similar).

```tsx
// Ejemplo de manejo de fallback en el componente de tarjeta
const [imgSrc, setImgSrc] = useState(product.preview_url || product.imagen_url);

<img 
  src={imgSrc} 
  alt={product.nombre}
  onError={() => setImgSrc(product.imagen_url)} // Si falla el preview, muestra la imagen original que sí funciona en el mockup
/>
