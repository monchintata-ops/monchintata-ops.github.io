# Ajuste Exacto de Posición para el Termo

## Objetivo
Alinear el área de estampado del termo exactamente con la referencia visual `ejemplotermo.jpg`.

---

## 1. Coordenadas Exactas (`lib/mockup-config.ts`)

Ajustar los valores de `printArea` en la clave `termo`:

- `x`: `0.18` (18% desde la izquierda para dar espacio respecto al asa)
- `y`: `0.32` (32% desde arriba, colocándolo centrado en la sección ancha superior)
- `width`: `0.48` (48% de ancho para una mayor presencia)
- `height`: `0.28` (28% de alto)
- `curvature`: `0.08` (mantiene el efecto cilíndrico)

---

## 2. Verificación
1. Validar compilación: `.\node_modules\.bin\tsc.cmd --noEmit`.
2. Confirmar cambios con `git add`, `commit` y `push`.
