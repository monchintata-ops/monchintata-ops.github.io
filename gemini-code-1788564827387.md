# Especificación: Input de Carga para Asset de Mockup en Modal Admin

## Objetivo
Actualizar el modal/formulario "Agregar nuevo diseño" en el panel de administración para incorporar un tercer campo de carga de archivo destinado al asset transparente del mockup (`diseno_mockup_url`).

---

## 1. Cambios en el Formulario del Modal

Agregar una nueva fila o campo de entrada entre los archivos existentes:

- **Campo 1:** Vista previa comercial (`imagen_preview_url` - Hoja A3/A4).
- **Campo 2 (NUEVO):** Diseño para Mockup (`diseno_mockup_url` - PNG transparente de logo/elemento aislado).
- **Campo 3:** Archivo de impresión original (`archivo_r2_key` / `archivo_original_url`).

---

## 2. Lógica de Subida (Upload Handler)

- Procesar el nuevo archivo subido mediante el selector.
- Almacenarlo en el bucket/storage correspondiente (ej. `/mockups/` o carpeta pública de activos).
- Incluir la URL resultante en el payload de creación/edición enviado a Supabase bajo la columna `diseno_mockup_url`.

---

## 3. Verificación
1. Validar la compilación de TypeScript con `.\node_modules\.bin\tsc.cmd --noEmit`.
2. Confirmar commit y push a `main`.
