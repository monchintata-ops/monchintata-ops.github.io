# Especificación: 3 Recursos por Producto (Seguridad y Multi-Mockup)

## Objetivo
1. Administrar 3 archivos de imagen por producto en el esquema de datos:
   - `archivo_original_url`: SVG/PNG alta res (protegido en Supabase).
   - `imagen_preview_url`: Hoja A3/A4 comercial con marcas de agua.
   - `diseno_mockup_url`: PNG transparente aislado de baja resolución (112px) para el Canvas.
2. Reactivar las 5 prendas en la galería: Camisa Negra, Camisa Blanca, Gorra, Taza y Termo.

---

## 1. Actualización de Tipos (`lib/types.ts` o modelo de Producto)
Asegurar que la interfaz de `Producto` admita el nuevo campo:
```typescript
export interface Producto {
  id: string;
  titulo: string;
  precio: number;
  imagen_preview_url: string; // Hoja A3/A4
  diseno_mockup_url?: string; // Logo 112px para Canvas
  // ...demás campos
}
