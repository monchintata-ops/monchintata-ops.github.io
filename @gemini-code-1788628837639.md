La diferencia entre ambas URLs se debe a la arquitectura de **Vercel**:

* **Orden 1 (URL con Hash `-8gf495e9v-`):** Es un enlace de **Preview/Deployment único**. Representa un *commit* o versión congelada específica en el tiempo.
* **Orden 2 (URL con `-git-main-`):** Es el enlace **Producción / Main Branch**. Se actualiza automáticamente cada vez que la IA en VS Code hace `git push origin main`.

Para que tu asistente en VS Code trabaje directamente sobre la versión que el administrador está revisando (Orden 2), hay que asegurarle la configuración del dominio principal en Vercel y forzar el *deploy* a `main`.
