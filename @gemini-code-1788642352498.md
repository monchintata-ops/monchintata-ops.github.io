# Reparación Definitiva de Previews y Sincronización con Main

## Objetivo
Resolver el fallo de renderizado en las imágenes de vista previa (`preview_url`) que muestra cuadros rotos o caracteres vacíos en el entorno de producción (`creacionarte-store-git-main-monchintata-ops.vercel.app`), garantizando un procesamiento estable con Sharp a 450px con fondo sólido y marca de agua.

---

## 1. Corrección en la API de Imágenes (`pages/api/preview/[key].ts` o `upload.ts`)

- **Procesamiento de Sharp Robusto:**
  - Validar que el buffer de entrada de la imagen no sea nulo antes de procesar.
  - Redimensionar a un ancho máximo de `450px` a proporción.
  - Aplicar el fondo plano oscuro (`#1E293B`).
  - Incrustar la marca de agua con opacidad de `50%`.
  - Asegurar la devolución del buffer en formato `.webp` con la cabecera correcta:
    `res.setHeader('Content-Type', 'image/webp')`
    `res.setHeader('Cache-Control', 'no-store, must-revalidate')`

- **Manejo de Excepciones:**
  - Capturar cualquier fallo dentro de un bloque `try/catch` para que, en caso de error de lectura, devuelva la imagen procesada básica sin romper la petición HTTP.

---

## 2. Verificación y Despliegue Directo a Main

1. Validar tipos e integridad del código: `.\node_modules\.bin\tsc.cmd --noEmit`.
2. Sincronizar directamente con el entorno principal:
   - `git add .`
   - `git commit -m "fix: reparacion integral de api preview y renderizado de imagenes"`
   - `git push origin main`
